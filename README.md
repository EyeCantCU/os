# Stereo

## Overview

Like `mono` but with more stuff.

## Garbage Collection

Stereo contains the tools used to perform garbage collection of older packages across Chainguard's APK repositories (wolfi, enterprise and extras).

Details on these tools an how to use them can be found in the [Shrink](./docs/shrink/README.md) documentation.

## Transitions

Stereo contains tools to help perform shared library transitions - see the [TRANSITION](./docs/TRANSITION.md) for more details.
